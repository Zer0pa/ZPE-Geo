# Security Policy

## Supported Scope

Security reports are accepted for the current `main` branch, the published `zpe-geo` package, and repo-local proof or validation material that ships from this repository.

Raw external corpora, private operator infrastructure, RunPod scratch state, and downstream deployments are outside this repo's supported security scope unless a vulnerability is reproducible from the public package or committed artifacts.

## Reporting

Report suspected vulnerabilities privately to `architects@zer0pa.ai`.

Include:

- affected version, commit, or package artifact
- reproduction steps
- expected impact
- any proof-of-concept material needed to reproduce the issue

Do not open public issues for exploitable security reports before triage.

## Response Targets

- Initial acknowledgement: within 5 business days.
- Triage update: within 10 business days after acknowledgement.
- Post-triage: remediation, mitigation notes, or a documented non-applicability decision based on the verified scope.

If a report affects a shared portfolio component outside this repo, the response may route through the owning repository while keeping the ZPE-Geo issue linked to the affected package or artifact.
